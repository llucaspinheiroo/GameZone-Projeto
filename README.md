# 🎮 GameZone Retro

Projeto desenvolvido em **HTML** com o objetivo de criar uma página simples de uma loja fictícia voltada para jogos e produtos retrô.

## 📌 Sobre o projeto

A **GameZone Retro** é uma página temática para pessoas que gostam de videogames clássicos. O site apresenta ofertas de jogos antigos, informações sobre a loja e uma lista de produtos encontrados no catálogo.

## 🕹️ Produtos

O projeto apresenta alguns jogos clássicos e seus respectivos consoles:

- Super Mario 64 — Nintendo 64 — R$ 120,00
- Crash Bandicoot — PlayStation — R$ 100,00
- Sonic 2 — Mega Drive — R$ 80,00

Além dos jogos, a página também apresenta consoles antigos, controles e acessórios como parte da proposta da loja.

## 💻 Tecnologias utilizadas

- HTML5
- Tabelas HTML
- Listas ordenadas
- Imagens
- Elementos de texto e formatação
